## 2. 适用范围

- 当前前端工作台、认证、排产任务、版本治理、Gantt 本地交互。
- 当前后端 `/api/v1/**` 接口访问边界。
- 当前不包含完整企业级 RBAC、审批流和组织级权限体系。

## 3. 当前权限模型概述

### 3.1 当前已实现的权限模型

当前系统实际生效的权限边界只有两层：

1. **未登录用户**
   - 可以访问登录页。
   - 可以调用：`/api/v1/auth/login`、`/api/v1/auth/session`、`/api/v1/auth/logout`、`/api/v1/health`。
   - 不能访问其他业务接口。

2. **已登录用户**
   - 可以访问当前工作台全部能力。
   - 可以查看版本、运行样例排产、查询任务状态、发布版本、修改自身账号。
   - 当前并未在代码中区分“排产员 / 管理层 / 审核人 / 只读用户”。

### 3.2 当前实现依据

- 业务接口鉴权由 `ApiAuthenticationFilter` 控制。
- 当前仅对 `/api/v1/auth/login`、`/api/v1/auth/session`、`/api/v1/auth/logout`、`/api/v1/health`、`OPTIONS` 放行。
- 其余 `/api/v1/**` 业务接口必须已有有效会话。

## 7. 状态流转总览

当前系统关键状态主要包括：

1. 登录认证状态。
2. 排产任务状态。
3. 版本状态。
4. Gantt 本地草稿状态。
5. 账号设置表单状态。

## 8. 登录认证状态流转

### 8.1 状态定义

| 状态 | 含义 |
| --- | --- |
| 未认证 | 当前无有效会话 |
| 已认证 | 当前存在有效会话 |
| 会话失效 | 原有会话不可用，需要重新登录 |

### 8.2 状态流转

```text
未认证
  -> 登录成功 -> 已认证
  -> 登录失败 -> 未认证

已认证
  -> 刷新页面且会话有效 -> 已认证
  -> 主动登出 -> 未认证
  -> 会话失效/接口401 -> 未认证
```

### 8.3 关键说明

- 前端启动时会先做会话检查。
- 任一业务请求返回 401 时，前端会清空当前工作台状态并返回登录页。

## 9. 排产任务状态流转

### 9.1 后端任务状态定义

| 状态 | 含义 |
| --- | --- |
| PENDING | 任务已创建，尚未开始执行 |
| RUNNING | 后台正在调用求解器 |
| DONE | 求解成功并已生成版本 |
| FAILED | 求解失败或执行异常 |

### 9.2 状态流转

```text
PENDING
  -> 异步执行开始 -> RUNNING
RUNNING
  -> 求解成功 -> DONE
  -> 求解失败/异常 -> FAILED
DONE
  -> 终态
FAILED
  -> 终态
```

### 9.3 前端任务显示状态

| 前端状态 | 对应含义 | 说明 |
| --- | --- | --- |
| Idle | 当前没有在跟踪任务 | 默认状态 |
| Submitting | 正在提交样例排产请求 | 前端临时状态 |
| Polling | 已获得 jobId，正在轮询 | 前端临时状态 |
| Done | 任务完成，自动加载版本 | 前端展示层状态 |
| Failed | 任务失败，展示错误原因 | 前端展示层状态 |

## 10. 版本状态流转

### 10.1 当前版本状态定义

| 状态 | 含义 |
| --- | --- |
| DRAFT | 新生成结果版本，尚未被确认发布 |
| PUBLISHED | 当前确认采用的版本 |
| ARCHIVED | 历史已发布版本，被后续发布版本替代 |

### 10.2 状态流转

```text
DRAFT
  -> 发布 -> PUBLISHED

PUBLISHED
  -> 其他版本发布 -> ARCHIVED

ARCHIVED
  -> 当前 rollback/publish 指向该版本 -> PUBLISHED
```

### 10.3 关键说明

- 当前系统始终保持“单一已发布版本”语义。
- 当前 rollback 接口的实际行为等同于重新 publish 指定版本，不代表完整业务回滚语义。

## 11. Gantt 本地草稿状态流转

### 11.1 当前状态定义

| 状态 | 含义 |
| --- | --- |
| Clean | 当前没有本地草稿 |
| Dirty | 用户已做本地拖拽调整 |
| Conflict | 本地草稿与任务或停机窗口重叠 |

### 11.2 状态流转

```text
Clean
  -> 拖拽任务 -> Dirty
Dirty
  -> 发生重叠冲突 -> Conflict
Dirty
  -> 重置草稿 -> Clean
Conflict
  -> 调整到无冲突 -> Dirty
Conflict
  -> 重置草稿 -> Clean
```

### 11.3 关键说明

- 当前本地草稿只存在于前端内存中，不回写后端。
- `pinned` 任务当前不可拖拽。

## 12. 账号设置表单状态流转

| 状态 | 触发条件 | 说明 |
| --- | --- | --- |
| 默认态 | 打开账号设置弹窗 | 表单可编辑 |
| Pending | 提交账号更新请求 | 前端按钮/表单进入提交中状态 |
| Success | 修改成功 | 当前用户名刷新 |
| Error | 当前密码错误/密码不合法/请求失败 | 显示错误提示 |

## 13. 当前实现限制

- 当前权限边界仍然是“登录态”而不是“角色态”。
- 发布版本尚未限制为管理角色独占。
- rollback 没有独立业务权限语义。
- Gantt 本地草稿没有进入正式审批或重排流程。

## 14. 下一阶段建议

- 在版本治理阶段优先引入基础角色模型：排产员、审核/管理、只读。
- 将 publish、rollback、diff 的权限边界和业务动作一起定义，不单独只做接口控制。
- 对本地草稿是否升级为正式调整流程，要先明确审批和落库语义。
