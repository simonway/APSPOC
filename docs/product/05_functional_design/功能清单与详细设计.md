## 3. 单功能设计

### FD-01 登录与会话管理

#### 3.1 目标

- 业务目标：保证工作台和排产数据仅对已登录用户开放。
- 用户价值：用户进入系统后即可安全使用工作台，不需要额外命令行操作。

#### 3.2 使用入口

| 项目 | 内容 |
| --- | --- |
| 入口页面 | P-01 登录页 |
| 触发动作 | 打开系统、提交登录、刷新页面、点击登出 |
| 前置条件 | 认证服务可用，存在合法账号 |
| 后置结果 | 已登录进入工作台；未登录继续停留在登录页 |

#### 3.3 交互流程

| 步骤 | 用户动作 | 前端处理 | 后端处理 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | 打开系统 | 调用会话检查接口 | 返回 authenticated 状态 | 展示登录页或工作台 |
| 2 | 输入账号密码并提交 | 发送登录请求 | 校验凭证并写入会话 | 登录成功/失败反馈 |
| 3 | 已登录后刷新页面 | 再次检查会话并刷新版本 | 返回当前会话用户 | 恢复工作台状态 |
| 4 | 点击登出 | 调用登出接口并清理状态 | 销毁会话 | 返回登录页 |

#### 3.4 字段与参数

| 字段 | 含义 | 来源 | 是否必填 | 校验规则 | 默认值 |
| --- | --- | --- | --- | --- | --- |
| username | 登录用户名 | 用户输入 | 是 | 非空 | 无 |
| password | 登录密码 | 用户输入 | 是 | 非空 | 无 |

#### 3.5 状态流转

| 当前状态 | 触发事件 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| 未认证 | 打开系统 | 未认证/已认证 | 根据会话校验结果决定 |
| 未认证 | 登录成功 | 已认证 | 进入工作台 |
| 未认证 | 登录失败 | 未认证 | 停留在登录页并提示 |
| 已认证 | 会话失效 | 未认证 | 清理前端状态并返回登录页 |
| 已认证 | 用户登出 | 未认证 | 主动退出系统 |

#### 3.6 权限控制

| 角色 | 可见 | 可操作 | 限制说明 |
| --- | --- | --- | --- |
| 排产员 | 是 | 登录、查看工作台、发起业务操作 | 当前与管理层权限未区分 |
| 管理层 | 是 | 登录、查看工作台、发布版本 | 当前与排产员权限未区分 |
| 访客/未登录用户 | 仅登录页 | 登录 | 无法访问业务接口 |

#### 3.7 异常场景

| 异常编号 | 场景 | 前端反馈 | 后端处理 | 用户引导 |
| --- | --- | --- | --- | --- |
| ERR-01 | 用户名或密码错误 | 登录页提示无效凭证 | 返回 401 | 重新输入账号密码 |
| ERR-02 | 会话失效 | 清空工作台状态并提示会话过期 | 返回 401 | 重新登录 |

#### 3.8 日志与审计

| 事件 | 记录内容 | 用途 |
| --- | --- | --- |
| 登录/登出 | 当前版本未提供独立审计查询界面 | 基础认证追踪待后续补齐 |
| 会话检查 | 当前版本未单独落库 | 页面访问控制 |

### FD-02 样例排产触发

#### 3.1 目标

- 业务目标：提供一个零配置的排产演示入口。
- 用户价值：用户无需准备业务数据即可快速看到系统能力。

#### 3.2 使用入口

| 项目 | 内容 |
| --- | --- |
| 入口页面 | P-02 主工作台 |
| 触发动作 | 点击 `Run Sample Schedule` |
| 前置条件 | 用户已登录，后端和求解器可用 |
| 后置结果 | 创建后台任务并进入轮询 |

#### 3.3 交互流程

| 步骤 | 用户动作 | 前端处理 | 后端处理 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | 点击样例排产 | 设置 loading 并发送请求 | 构造样例场景 | 调用创建任务接口 |
| 2 | 等待响应 | 记录 jobId | 保存任务初始状态 | 返回任务摘要 |
| 3 | 等待求解 | 自动进入轮询 | 异步执行求解 | 更新任务状态 |

#### 3.4 字段与参数

| 字段 | 含义 | 来源 | 是否必填 | 校验规则 | 默认值 |
| --- | --- | --- | --- | --- | --- |
| scenarioName | 场景名称 | 系统内置样例 | 是 | 固定样例值 | `plant-scale-control-deck` |
| resources/tasks/downtimes | 样例资源、任务、停机数据 | 系统内置样例 | 是 | 由后端构造 | 固定样例集 |
| objectiveWeights | 目标函数权重 | 系统内置样例 | 是 | tardiness>0、makespan>=0 | `100/1` |
| solverConfig | 求解参数 | 系统内置样例 | 是 | 正整数 | `10s/4workers` |

#### 3.5 状态流转

| 当前状态 | 触发事件 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| Idle | 点击运行样例 | Submitting | 前端开始提交 |
| Submitting | 创建任务成功 | Polling | 获得 jobId |
| Polling | 任务完成 | Done | 自动加载新版本 |
| Polling | 任务失败 | Failed | 展示失败原因 |

#### 3.6 权限控制

| 角色 | 可见 | 可操作 | 限制说明 |
| --- | --- | --- | --- |
| 排产员 | 是 | 可触发样例排产 | 需登录 |
| 管理层 | 是 | 当前也可触发 | 当前未区分角色 |
| 访客/未登录用户 | 否 | 否 | 无法访问工作台 |

#### 3.7 异常场景

| 异常编号 | 场景 | 前端反馈 | 后端处理 | 用户引导 |
| --- | --- | --- | --- | --- |
| ERR-01 | 样例提交失败 | 状态卡片显示提交失败 | 返回错误响应 | 检查服务可用性 |
| ERR-02 | 求解器不可用 | 状态卡片显示失败原因 | 任务标记 FAILED | 重新尝试或排查求解器 |

#### 3.8 日志与审计

| 事件 | 记录内容 | 用途 |
| --- | --- | --- |
| 样例任务创建 | jobId、scenarioName、创建时间 | 跟踪一次排产任务 |
| 求解结果落库 | versionId、versionName、状态 | 跟踪结果沉淀 |

### FD-03 通用排产任务提交 API

#### 3.1 目标

- 业务目标：为真实业务建模页和外部系统接入提供标准排产入口。
- 用户价值：后续无需依赖样例场景，也能提交正式排产请求。

#### 3.2 使用入口

| 项目 | 内容 |
| --- | --- |
| 入口页面 | 当前无正式前端录入页 |
| 触发动作 | 调用 `POST /api/v1/schedule/jobs` |
| 前置条件 | 已登录，请求体字段完整 |
| 后置结果 | 创建异步任务 |

#### 3.3 交互流程

| 步骤 | 用户动作 | 前端处理 | 后端处理 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | 组装排产请求 | 当前由外部调用方负责 | 接收请求体 | 开始参数校验 |
| 2 | 提交请求 | 无内置页面 | 校验资源引用和停机窗口合法性 | 通过/拒绝 |
| 3 | 校验通过 | 无 | 创建 job 并异步调用求解器 | 返回任务摘要 |

#### 3.4 字段与参数

| 字段 | 含义 | 来源 | 是否必填 | 校验规则 | 默认值 |
| --- | --- | --- | --- | --- | --- |
| scenarioName | 场景名称 | 调用方 | 是 | 非空 | 无 |
| scheduleStartAt | 排产起始时间 | 调用方 | 是 | Instant | 无 |
| horizonMinutes | 规划时域 | 调用方 | 是 | 正整数 | 无 |
| resources | 资源列表 | 调用方 | 是 | 非空 | 无 |
| tasks | 任务列表 | 调用方 | 是 | 非空 | 无 |
| downtimes | 停机窗口 | 调用方 | 否 | start<end<=horizon | 空数组 |
| objectiveWeights | 目标权重 | 调用方 | 否 | tardiness>0、makespan>=0 | `100/1` |
| solverConfig | 求解参数 | 调用方 | 否 | 正整数 | `10s/4workers` |

#### 3.5 状态流转

| 当前状态 | 触发事件 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| 请求待提交 | 调用接口 | 已提交 | 进入后端校验 |
| 已提交 | 校验通过 | 异步执行中 | 创建后台任务 |
| 已提交 | 校验失败 | 已拒绝 | 返回 4xx 错误 |
| 异步执行中 | 求解完成 | 任务完成 | 生成版本 |
| 异步执行中 | 求解失败 | 任务失败 | 记录错误信息 |

#### 3.6 权限控制

| 角色 | 可见 | 可操作 | 限制说明 |
| --- | --- | --- | --- |
| 排产员 | 是 | 未来可通过前端录入页发起 | 当前需登录并通过 API 调用 |
| 管理层 | 是 | 通常只读 | 当前未区分角色 |
| 访客/未登录用户 | 否 | 否 | 业务接口需要会话 |

#### 3.7 异常场景

| 异常编号 | 场景 | 前端反馈 | 后端处理 | 用户引导 |
| --- | --- | --- | --- | --- |
| ERR-01 | candidateResourceIds 引用不存在资源 | 调用方收到错误消息 | 返回 400 | 修正资源定义 |
| ERR-02 | 停机窗口不合法 | 调用方收到错误消息 | 返回 400 | 修正窗口边界 |

#### 3.8 日志与审计

| 事件 | 记录内容 | 用途 |
| --- | --- | --- |
| API 创建任务 | jobId、scenarioName | 关联一次排产调用 |
| 参数校验失败 | 错误信息 | 协助调用方定位问题 |

### FD-04 任务状态轮询

#### 3.1 目标

- 业务目标：让用户及时知道后台任务是否完成。
- 用户价值：用户无需刷新页面即可获得排产结果。

#### 3.2 使用入口

| 项目 | 内容 |
| --- | --- |
| 入口页面 | P-02 主工作台 |
| 触发动作 | 样例任务创建成功后自动触发 |
| 前置条件 | 已获得 jobId |
| 后置结果 | 任务完成后自动加载版本 |

#### 3.3 交互流程

| 步骤 | 用户动作 | 前端处理 | 后端处理 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | 无 | 按固定频率查询任务状态 | 返回任务状态 | 状态文案更新 |
| 2 | 无 | 若为 RUNNING/PENDING 继续轮询 | 无 | 保持等待 |
| 3 | 无 | 若为 DONE 停止轮询并加载版本 | 返回 versionId | 跳转到结果查看 |
| 4 | 无 | 若为 FAILED 停止轮询 | 返回 errorMessage | 展示失败原因 |

#### 3.4 字段与参数

| 字段 | 含义 | 来源 | 是否必填 | 校验规则 | 默认值 |
| --- | --- | --- | --- | --- | --- |
| jobId | 任务编号 | 创建任务返回值 | 是 | 非空 | 无 |
| status | 任务状态 | 后端返回 | 是 | PENDING/RUNNING/DONE/FAILED | 无 |
| versionId | 结果版本编号 | 后端返回 | 否 | DONE 时应存在 | 无 |
| errorMessage | 错误信息 | 后端返回 | 否 | FAILED 时可返回 | 无 |

#### 3.5 状态流转

| 当前状态 | 触发事件 | 下一状态 | 说明 |
| --- | --- | --- | --- |
| PENDING | 异步执行启动 | RUNNING | 后台开始求解 |
| RUNNING | 求解成功 | DONE | 生成版本并写回 job |
| RUNNING | 求解失败 | FAILED | 记录错误信息 |
| DONE | 前端加载版本 | DONE | 终态 |
| FAILED | 前端展示错误 | FAILED | 终态 |

#### 3.6 权限控制

| 角色 | 可见 | 可操作 | 限制说明 |
| --- | --- | --- | --- |
| 排产员 | 是 | 可查看状态 | 需登录 |
| 管理层 | 是 | 当前也可查看状态 | 当前未区分角色 |
| 访客/未登录用户 | 否 | 否 | 无法访问任务接口 |

#### 3.7 异常场景

| 异常编号 | 场景 | 前端反馈 | 后端处理 | 用户引导 |
| --- | --- | --- | --- | --- |
| ERR-01 | 轮询接口失败 | 显示 polling error | 无额外处理 | 刷新页面或重新尝试 |
| ERR-02 | DONE 但版本无法加载 | 显示接口错误 | 返回 404/异常 | 排查版本数据 |

#### 3.8 日志与审计

| 事件 | 记录内容 | 用途 |
| --- | --- | --- |
| 任务状态更新 | jobId、status、versionId | 跟踪任务生命周期 |
| 失败结果 | errorMessage | 故障定位 |

#### 3.3 交互流程

#### 3.4 字段与参数

#### 3.5 状态流转

#### 3.6 权限控制

| 角色 | 可见 | 可操作 | 限制说明 |

#### 3.7 异常场景

### FD-06 版本发布

#### 3.1 目标

- 业务目标：标记当前确认采用的排产方案。
- 用户价值：用户能够明确哪一个版本是当前生效方案。

#### 3.2 使用入口

| 项目 | 内容 |
| --- | --- |
| 入口页面 | P-03 Viewer |
| 触发动作 | 点击 `Publish Version` |
| 前置条件 | 已选中版本且当前状态不是 PUBLISHED |
| 后置结果 | 目标版本变为 PUBLISHED，其余已发布版本归档 |

#### 3.3 交互流程

| 步骤 | 用户动作 | 前端处理 | 后端处理 | 输出 |
| --- | --- | --- | --- | --- |
| 1 | 选择某个草稿版本 | 启用发布按钮 | 无 | 准备发布 |
| 2 | 点击发布 | 调用发布接口并临时禁用按钮 | 目标版本置为 PUBLISHED | 返回更新后的版本 |
| 3 | 等待完成 | 刷新版本列表和当前详情 | 其他已发布版本置为 ARCHIVED | 页面状态同步更新 |

#### 3.4 字段与参数

| 字段 | 含义 | 来源 | 是否必填 | 校验规则 | 默认值 |

## 5. 研发实现关注点

- 前端关注点：当前主工作台已经承担版本查看、任务状态、Gantt 交互等核心功能，但缺少真实业务建模页；继续扩展时要避免把演示逻辑和正式业务录入逻辑混在一起。
- 后端关注点：当前任务执行为应用内异步模式，版本落库和状态流转已形成基础闭环；后续要重点补版本治理和更明确的回滚语义。
- 求解器关注点：当前支持候选资源择一、停机窗口避让、pinned 约束和基础目标函数；后续高级 APS 约束需谨慎扩展数据模型。
- 数据一致性关注点：发布版本会归档历史已发布版本；当前 Gantt 本地草稿不会写回后端，文档和界面都要明确这一点。
