## 7. 变更控制规则

对第三期正式样本，建议统一遵循以下规则：

1. 若修改 `01~07` 或 `14` 源输入，必须重新生成 `08~13` 产物并检查 README 口径。
2. 若任务数、precedence 数、库存覆盖口径发生变化，必须同步更新 `09_uat_expected_checks.md`、`10_generated_operation_metadata.json` 和相关产品文档。
3. 若样本引入第四期复杂规则，不得继续使用 `snow_beer_main_chain_phase3` 原路径，应新建第四期样本或明确分支版本。
4. 若样本仅做注释、描述或非语义修订，仍建议在变更记录中注明影响范围。
5. 样本变更后，至少应重新执行一次 `build_uat_sample_package.py --check` 和一次面向该目录的 smoke。
