## 4. 当前文档结论摘要

- 当前 APSPOC 已具备进入下一阶段的技术和产品基础，但下一阶段必须聚焦在 UAT 可用，而不是继续扩展演示功能。
- 当前最关键的 6 个主题是：
  1. 试点范围冻结
  2. 真实/脱敏样本包
  3. 主数据导入与场景生成
  4. Solver Must 约束
  5. Gantt 评审与版本治理
  6. UAT 收口
- 当前建议所有新增需求都先映射到 V1~V5 路线图与 M0~M6 里程碑，再决定是否纳入当前阶段。

## 5. 建议下一步

1. 组织一次范围与样本冻结会，先拿下 M0。
2. 把 `真实业务样本映射说明.md` 和 `接口清单与字段契约.md` 作为 M1/M2 的工作基础。
3. 让产品、研发、算法共同基于 UAT 样本补充 Must 约束和失败原因分类。
4. 在开始 UAT 前，补齐审批、发布、回退、角色边界的统一口径。

## 6. 维护规则

- 文档状态从“评审版”升级到“UAT 版”或“试点版”时，需同步更新本索引。
- 若某份文档进入归档，移入 `99_archive/` 并在本索引中说明替代文件。
- 任何影响范围、路线图、交付节奏、角色权限或接口边界的变化，都应同步更新 `变更记录.md`。
