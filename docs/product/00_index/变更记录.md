# 变更记录

## 1. 说明

本文档用于记录 `docs/product/` 产品文档体系的重要变更，重点记录结构性变化、关键结论变化和里程碑式补充，不记录每一次微小措辞修改。

## 2. 记录规则

- 记录“为什么变更”，而不仅是“改了什么”。
- 对会影响阅读顺序、范围判断、交付计划或接口边界的更新，必须记录。
- 若后续某份文档进入评审版、试点版或被归档，也应在此保留记录。
