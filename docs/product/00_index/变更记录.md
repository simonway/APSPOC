# 变更记录

## 1. 说明

本文档用于记录 `docs/product/` 产品文档体系的重要变更，重点记录结构性变化、关键结论变化和里程碑式补充，不记录每一次微小措辞修改。

## 2. 记录规则

- 记录“为什么变更”，而不仅是“改了什么”。
- 对会影响阅读顺序、范围判断、交付计划或接口边界的更新，必须记录。
- 若后续某份文档进入评审版、试点版或被归档，也应在此保留记录。

## 4. 当前阶段结论

- 截至 2026-05-08，`docs/product/` 仍以 `v1.0 MVP/UAT 规划版` 为主体，但关键路线图文档已增加“当前实现状态补记”。
- 当前推荐统一口径为：二期核心能力完成，可进入业务演示/UAT；二期产品化收尾未全部完成。
- 当前文档更新继续以现有代码和已实现能力为基线，不把未落地能力写成已实现事实。

## 5. 下一步记录建议

后续出现以下变化时，建议新增记录：

1. M0 范围与 UAT 样本正式冻结。
2. Recipe / Demand 主数据口径确认，导致 PRD、接口或数据规则变化。
3. rollback / approval / publish 语义正式落地。
4. Redis-backed queue 或等价执行架构方案定版。
5. UAT 通过、试点版或正式集成版结论形成。
