# 变更记录

## 1. 说明

本文档用于记录 `docs/product/` 产品文档体系的重要变更，重点记录结构性变化、关键结论变化和里程碑式补充，不记录每一次微小措辞修改。

## 2. 记录规则

- 记录“为什么变更”，而不仅是“改了什么”。
- 对会影响阅读顺序、范围判断、交付计划或接口边界的更新，必须记录。
- 若后续某份文档进入评审版、试点版或被归档，也应在此保留记录。

## 4. 当前阶段结论

- 截至 2026-04-20，`docs/product/` 已形成一套完整的第一版产品文档骨架。
- 当前文档体系已覆盖：范围、流程、需求、页面、功能、数据、接口、测试、路线图、计划、风险、非功能、集成、权限、上线准备、术语、索引和真实业务样本映射说明。
- 当前文档全部以**现有代码和已实现行为**为基础，而不是假设未来状态。

## 5. 下一步记录建议

后续出现以下变化时，建议新增记录：

1. 文档从“第一版”进入“评审通过版”。
2. 真实业务录入方案确定，导致 PRD、流程、接口边界变化。
3. rollback / diff / 发布语义正式调整。
4. ERP/MES/主数据系统开始正式联调。
5. 上线检查清单从 POC/试点版本升级为生产版本。
