> 本清单面向当前 APS POC 阶段的“演示发布 / 内部试点发布 / 联调发布”准备，不默认等同于正式生产上线手册。其目标是确保每次发布前，环境、接口、核心链路和边界认知一致。

## 2. 适用场景

| 场景 | 是否适用 | 说明 |
| --- | --- | --- |
| POC 演示环境发布 | 是 | 当前最主要场景 |
| 内部联调环境发布 | 是 | 当前推荐使用 |
| 业务试点环境发布 | 是 | 进入试点前需扩展更多检查项 |
| 正式生产环境上线 | 否 | 需后续单独形成生产级运行手册 |

## 3. 发布前提

- 当前版本范围、风险、对接边界已在文档中明确。
- 当前版本变更内容已完成自测或回归验证。
- 当前默认账号、端口、环境依赖已确认可用。
- 团队对“已实现能力 / 未实现能力”有一致认知。

- 不建议把当前版本描述为“正式生产可用”。
