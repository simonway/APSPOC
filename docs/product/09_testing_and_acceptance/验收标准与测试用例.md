## 2. 验收范围

- 本次验收覆盖的业务范围：登录认证、样例排产闭环、异步任务轮询、版本浏览、Gantt 展示、版本发布、账号设置与双语切换。
- 本次验收覆盖的系统范围：静态前端工作台、Spring Boot 后端、Python OR-Tools 求解器。
- 本次验收覆盖的接口范围：认证接口、排产任务接口、版本接口、健康检查接口。
- 本次验收不覆盖的内容：真实业务录入页、主数据导入、版本 diff、真实 rollback 审计、高级 APS 约束、MES/ERP 集成。

## 3. 验收入口与出口标准

### 3.1 入口标准

- PRD、业务流程、功能设计、数据/接口文档已完成第一版。
- 前后端与求解器本地环境可正常启动。
- 默认测试账号可用：`admin / admin123`。
- 样例排产能力可用，或可通过 `docs/sample-job-request.json` 发起标准排产请求。
- 当前已具备基础自动化测试：认证服务单元测试、求解器停机约束测试。

### 3.2 出口标准

- P0 缺陷全部关闭，P1 缺陷有明确规避方案且不阻断演示。
- 核心场景通过率 100%：登录、样例排产、任务轮询、版本查看、Gantt 查看、发布版本。
- 关键接口返回结果与文档契约一致。
- UAT 参与方确认当前版本可作为 POC 演示和下一阶段规划依据。
