## 当前状态补记（2026-05-08）

当前版本推荐统一口径为：

> 二期核心能力完成，可进入业务演示/UAT；二期产品化收尾未全部完成。

因此本文件中的验收项需要分两层理解：

- `当前必测项`：基于当前真实已实现能力，作为业务演示/UAT 的默认阻断项。
- `目标增强项`：只有在某次发布明确宣称已经落地时，才升级为当前轮次的阻断项。

当前默认不应把以下内容作为必过前提：

- 正式 `Admin / Planner / Approver / Viewer` 角色权限
- 正式 `approve / reject` 审批流
- 完整 `QUEUED / TIMEOUT / CANCELLED` 状态机

## 2. 验收范围

### 2.1 已具备基线验收

- 登录认证、会话、账号设置、双语。
- 样例排产、异步 job、轮询、版本生成。
- 版本列表、Gantt、KPI、history、diff。
- 模型导入导出基础能力。
- release note、ready-for-release、publish、rollback、审计基础。
- backend/solver 单测和 release smoke。

### 2.2 MVP/UAT 新增验收

- UAT_v1 真实/脱敏样本包。
- Resource / Recipe / Demand / Downtime / SetupRule 导入与错误报告。
- Demand + Recipe 生成 Operation 和排产场景。
- Solver Must 约束：资源能力、停机、固定任务、工序先后、基础换型。
- 异步执行：当前版本至少验证失败可见、状态可轮询；完整队列/状态机/超时/失败分类属于后续增强项。
- Gantt 业务评审：筛选、定位、异常高亮、业务字段详情。
- 版本治理基础：release notes、ready-for-release、publish、rollback、审计；正式审批和权限矩阵属于后续增强项。
- UAT 缺陷分级、操作手册、验收报告。

## 3. UAT 入口与出口标准

### 3.1 入口标准

- M0 范围、试点场景、Must/Should/Could 约束已冻结。
- UAT_v1 样本包已冻结，并通过导入校验。
- P0 产品文档、接口契约、数据字典、权限状态说明已同步。
- backend/solver 单测通过。
- release smoke 通过。
- UAT 环境、账号和数据版本已确认；若当前轮次不验角色权限，需在发布说明中明确。

### 3.2 出口标准

- 核心用例通过率 100%。
- P0 缺陷为 0。
- P1 缺陷有明确规避方案和修复计划。
- Must 硬约束 100% 不违反。
- 当前发布版本可追溯创建、提交待发布、发布、回退和发布原因；若当前轮次验正式审批流，则再追加审批追溯要求。
- 业务方形成“通过 / 有条件通过 / 不通过”的书面结论。

## 4. 缺陷分级

| 级别 | 定义 | 处理要求 |
| --- | --- | --- |
| P0 | 阻断 UAT 主流程、数据错误、违反 Must 硬约束、权限越权 | 必须修复后才能通过 |
| P1 | 影响 UAT 判断但有临时规避方案 | 可有条件通过，需明确修复计划 |
| P2 | 体验问题或非关键边界问题 | 记录后排期 |
| P3 | 优化建议 | 进入 backlog |

### 5.1 样本语义审计入口（2026-05-09 补充）

当前 UAT 对真实样本的验收，不应只看最终 Gantt 或 job 状态，还应检查样本生成物中的语义审计文件。

建议默认使用以下资料：

- 基础雪花样本说明：
  - [snow_beer_packaging_v1/00_readme.md](/Users/simon/Documents/MyProgramming/APSPOC/docs/sample-packages/snow_beer_packaging_v1/00_readme.md:1)
- 前后置专项样本说明：
  - [snow_beer_packaging_v1_precedence/00_readme.md](/Users/simon/Documents/MyProgramming/APSPOC/docs/sample-packages/snow_beer_packaging_v1_precedence/00_readme.md:1)
- 语义事实源：
  - `10_generated_operation_metadata.json`

验收时建议重点核对：

- `demandCoverages`
  - `requestedQuantity`
  - `inventoryCoveredQuantity`
  - `plannedQuantity`
  - `dueMinutes`
  - `priority`
- `operations`
  - `operationId`
  - `sequence`
  - `candidateResourceIds`
  - `predecessorOperationIds`
  - `materialInputs / materialOutputs`
  - `setupGroup`
- `precedencePairs`
- `setupRules`
- `bridgeAdjustments`

当前雪花样本的默认口径：

- `quantity` 使用预聚合 `lot`，不是原始 `KL`
- `priority` 使用样本人工冻结的业务紧急度，不是源文档直接字段
- `snow_beer_packaging_v1` 用于库存/换型/停机主链路演示
- `snow_beer_packaging_v1_precedence` 用于显式验证 `Recipe -> predecessorTaskIds -> solver precedence`

## 8. UI 人工补验清单

- 浏览器登录页与工作台双语切换。
- Gantt 任务拖拽、跨行移动、锁定/解锁、`Ctrl+Z`。
- “变更任务”点击后自动定位与自动解锁联动。
- 点击 `新增 / 调整 / 移除` 变更项后，高亮和状态反馈足够明显；若任务条不存在，则能回退定位到资源行。
- 拖拽任务条时，开始/结束时间标签以悬浮卡片形式显示，且不被任务条遮挡。
- 账号设置弹层与退出登录入口。
- 浏览器强刷后的静态资源缓存生效。
- 当前治理流下的 `ready-for-release / publish / rollback` 确认提示。
- 草稿/正式版本边界提示。
