## 3. 接口契约明细

### API-00 健康检查

#### 3.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 接口编号 | API-00 |
| 方法 | GET |
| 路径 | `/api/v1/health` |
| 调用方 | 前端/联调方 |
| 提供方 | Backend API |
| 鉴权方式 | 无 |
| 超时要求 | < 3s |

#### 3.2 请求参数

无。

#### 3.3 响应字段

| 字段 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| service | string | `aps-poc-backend` | 服务名 |
| status | string | `UP` | 当前健康状态 |
| timestamp | string | `2026-04-20T09:00:00Z` | 返回时间 |

#### 3.4 成功响应示例

```json
{
  "service": "aps-poc-backend",
  "status": "UP",
  "timestamp": "2026-04-20T09:00:00Z"
}
```

#### 3.5 失败响应示例

当前未定义统一错误体，服务不可用时通常表现为连接失败或 5xx。

#### 3.6 业务说明

- 接口目的：快速确认后端服务是否启动。
- 调用时机：启动检查、联调探活。
- 幂等要求：是。
- 排序/分页要求：无。
- 与页面/功能关系：前端不直接依赖该接口渲染页面。

### API-01 用户登录

#### 3.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 接口编号 | API-01 |
| 方法 | POST |
| 路径 | `/api/v1/auth/login` |
| 调用方 | 登录页 |
| 提供方 | Backend API |
| 鉴权方式 | 无 |
| 超时要求 | < 5s |

#### 3.2 请求参数

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| username | string | 是 | `admin` | 用户名，非空 |
| password | string | 是 | `admin123` | 密码，非空 |

#### 3.3 响应字段

| 字段 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| authenticated | boolean | `true` | 是否认证成功 |
| username | string | `admin` | 当前会话用户名 |

#### 3.4 成功响应示例

```json
{
  "authenticated": true,
  "username": "admin"
}
```

#### 3.5 失败响应示例

```json
{
  "message": "Invalid username or password"
}
```

#### 3.6 错误码

| 错误码 | 含义 | 触发条件 | 处理建议 |
| --- | --- | --- | --- |
| 401 | 未通过认证 | 用户名或密码错误 | 重新输入账号密码 |
| 400 | 请求不合法 | 字段缺失或为空 | 检查请求体 |

#### 3.7 业务说明

- 接口目的：创建登录会话。
- 调用时机：用户在登录页提交表单时。
- 幂等要求：否。
- 排序/分页要求：无。
- 与页面/功能关系：成功后进入工作台并加载版本数据。

### API-05 创建排产任务

#### 3.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 接口编号 | API-05 |
| 方法 | POST |
| 路径 | `/api/v1/schedule/jobs` |
| 调用方 | 外部调用方/后续业务录入页 |
| 提供方 | Backend API |
| 鉴权方式 | Session Cookie |
| 超时要求 | < 10s（仅提交任务，不等待求解完成） |

#### 3.2 请求参数

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| scenarioName | string | 是 | `reactor-poc-baseline` | 场景名称 |
| scheduleStartAt | string(datetime) | 是 | `2026-04-15T08:00:00Z` | 排产起点 |
| horizonMinutes | integer | 是 | `2880` | 规划时域，>0 |
| resources | object[] | 是 | 见示例 | 资源列表，非空 |
| tasks | object[] | 是 | 见示例 | 任务列表，非空 |
| downtimes | object[] | 否 | 见示例 | 停机窗口 |
| objectiveWeights | object | 否 | `{"tardiness":100,"makespan":1}` | 目标权重 |
| solverConfig | object | 否 | `{"timeLimitSeconds":10,"numSearchWorkers":4}` | 求解参数 |

#### 3.3 资源子对象

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | `reactor_01` | 资源编号 |
| label | string | 是 | `Reactor-01` | 资源名称 |
| resourceType | string | 是 | `REACTOR` | 资源类型 |
| sortOrder | integer | 是 | `1` | 排序号，>=0 |

#### 3.4 任务子对象

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | `batch_A` | 任务编号 |
| label | string | 是 | `Batch A` | 任务名称 |
| productCode | string | 是 | `A` | 产品编码 |
| durationMinutes | integer | 是 | `480` | 时长，>0 |
| dueMinutes | integer | 是 | `1080` | 到期分钟，>0 |
| priority | integer | 是 | `3` | 优先级，>0 |
| candidateResourceIds | string[] | 是 | `["reactor_01","reactor_02"]` | 候选资源 |
| pinnedResourceId | string | 否 | `reactor_01` | 固定资源 |
| pinnedStartMinutes | integer | 否 | `240` | 固定开始时间，>=0 |

#### 3.5 停机子对象

| 字段 | 类型 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| id | string | 是 | `maintenance_reactor_01_morning` | 停机编号 |
| resourceId | string | 是 | `reactor_01` | 资源编号 |
| startMinutes | integer | 是 | `240` | 开始分钟 |
| endMinutes | integer | 是 | `420` | 结束分钟 |
| downtimeType | string | 是 | `MAINTENANCE` | 停机类型 |
| source | string | 否 | `CALENDAR` | 来源，默认 `MANUAL` |
| description | string | 否 | `Preventive maintenance window` | 说明 |

#### 3.6 响应字段

| 字段 | 类型 | 示例 | 说明 |
| --- | --- | --- | --- |
| jobId | string | `job-123` | 后台任务编号 |
| scenarioName | string | `reactor-poc-baseline` | 场景名称 |
| status | string | `PENDING` | 任务状态 |
| solverStatus | string | `PENDING` | 求解状态 |
| versionId | string | `null` | 完成前为空 |
| errorMessage | string | `null` | 失败前为空 |
| createdAt | string(datetime) | `2026-04-20T09:00:00Z` | 创建时间 |
| completedAt | string(datetime) | `null` | 未完成前为空 |

#### 3.7 成功响应示例

```json
{
  "jobId": "job-123",
  "scenarioName": "reactor-poc-baseline",
  "status": "PENDING",
  "solverStatus": "PENDING",
  "versionId": null,
  "errorMessage": null,
  "createdAt": "2026-04-20T09:00:00Z",
  "completedAt": null
}
```

#### 3.8 失败响应示例

```json
{
  "message": "Task candidateResourceIds contains an unknown resource id"
}
```

#### 3.9 业务说明

- 接口目的：提交标准排产请求并创建异步作业。
- 调用时机：后续录入页提交排产，或外部系统发起调用。
- 幂等要求：否。
- 排序/分页要求：无。
- 与页面/功能关系：当前前端没有正式录入页，但后端能力已就绪。

### API-08 查询版本列表

#### 3.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 接口编号 | API-08 |
| 方法 | GET |
| 路径 | `/api/v1/versions` |
| 调用方 | 主工作台 |
| 提供方 | Backend API |
| 鉴权方式 | Session Cookie |
| 超时要求 | < 5s |

无。

#### 3.3 响应字段

返回数组，元素字段如下：

| 字段 | 类型 | 示例 | 说明 |

| totalWeightedTardiness | integer | `240` | KPI |
| totalMakespan | integer | `1680` | KPI |

- 调用时机：登录成功、刷新、任务完成后。
- 幂等要求：是。
- 排序/分页要求：当前按 `createdAt desc` 返回，无分页。
- 与页面/功能关系：左侧版本列表和顶部统计卡片依赖该接口。

## 5. 字段映射

### 5.1 排产请求到求解器请求映射

| 来源字段 | 目标字段 | 转换规则 | 是否必填 | 备注 |
| --- | --- | --- | --- | --- |
| `scenarioName` | `job.scenarioName` / `version.scenarioDescription` | 原样透传到任务和版本说明 | 是 | 用于任务和版本命名 |
| `scheduleStartAt` | `solverRequest.scheduleStartAt` | 原样透传 | 是 | 也是 Gantt 时间换算基准 |
| `resources[].resourceType` | `solverRequest.resources[].resourceType` | Java 枚举名称转字符串 | 是 | 如 `REACTOR` |

| `solverConfig` | `solverRequest.solverConfig` | 缺省时填 `10s/4workers` | 否 | 后端补默认值 |

### 5.2 求解器响应到版本/Gantt 映射

| 来源字段 | 目标字段 | 转换规则 | 是否必填 | 备注 |
