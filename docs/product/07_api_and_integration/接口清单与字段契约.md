## 4. 核心字段契约

### 4.1 创建排产任务请求

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| scenarioName | string | 是 | 场景名称 |
| scheduleStartAt | datetime | 是 | 排产起点 |
| horizonMinutes | integer | 是 | 规划时域 |
| resources | object[] | 是 | 当前资源列表 |
| tasks | object[] | 是 | solver 可直接排程任务 |
| downtimes | object[] | 否 | 停机窗口 |
| objectiveWeights | object | 否 | 迟交/makespan 权重 |
| solverConfig | object | 否 | 求解时间、worker 数 |
| dataVersion | string | MVP | 来源数据版本 |

### 4.2 MVP Task/Operation 扩展字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| predecessorTaskIds | string[] | MVP | 工序先后约束 |
| setupGroup | string | MVP | 换型分组 |
| demandId | string | MVP | 来源需求 |
| operationCode | string | MVP | 来源工序 |
| operationSequence | integer | MVP | 工序顺序 |

### 4.3 导入响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| importId | string | 导入批次编号 |
| dataVersion | string | 数据版本 |
| status | string | VALIDATED / VALIDATION_FAILED 等 |
| successCount | integer | 成功行数 |
| failureCount | integer | 失败行数 |
| errors | object[] | 行级/字段级错误 |

`errors` 子对象：`sheetName`、`rowNumber`、`fieldName`、`rawValue`、`errorCode`、`message`、`suggestion`。

### 4.4 Job 状态响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| jobId | string | 排程任务编号 |
| status | string | 当前四态已实现；MVP 目标扩展 QUEUED/TIMEOUT/CANCELLED |
| solverStatus | string | solver 原始状态或失败分类 |
| versionId | string | 成功后关联版本 |
| errorMessage | string | 用户可理解错误 |
| failureReason | string | MVP 标准错误分类 |
| createdAt | datetime | 创建时间 |
| completedAt | datetime | 完成时间 |
| solveDurationMs | integer | 求解耗时 |

### 4.5 Version 治理字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| versionId | string | 版本编号 |
| status | string | DRAFT/READY_FOR_RELEASE/RELEASED/ARCHIVED/ROLLED_BACK 等 |
| releaseNote | string | 发布说明 |
| createdBy | string | 创建人 |
| submittedBy | string | 提交人 |
| approvedBy | string | 审批人 |
| publishedBy | string | 发布人 |
| previousReleasedVersionId | string | 发布前生效版本 |
| auditEvents | object[] | 审计事件 |

## 6. 错误响应建议

建议统一错误体：

```json
{
  "code": "IMPORT_VALIDATION_FAILED",
  "message": "Import validation failed",
  "details": [
    {
      "field": "candidateResourceIds",
      "message": "Unknown resource id reactor_99"
    }
  ],
  "requestId": "req-..."
}
```

标准错误分类：

- AUTH_REQUIRED
- PERMISSION_DENIED
- IMPORT_VALIDATION_FAILED
- INVALID_SCENARIO
- INFEASIBLE
- SOLVER_TIMEOUT
- SOLVER_UNAVAILABLE
- EXECUTION_FAILED

## 7. 鉴权与权限要求

- 认证接口和健康检查可匿名访问。
- 业务查询接口需登录。
- 导入、创建排程、试算、提交审批、审批、发布、回退需角色权限。
- 后端必须校验权限，前端隐藏按钮只是体验优化。
