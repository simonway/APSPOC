## 2. 设计原则

- 核心任务优先：当前页面围绕“登录、运行样例排产、查看结果、发布版本”四个关键动作组织。
- 信息分层展示：先展示版本概览和 KPI，再进入资源时间轴和任务细节。
- 结果可解释：任务条、停机窗口、KPI、版本状态同时可见，降低理解成本。
- 演示优先：当前 UI 重点支撑 POC 演示链路，而不是完整业务录入。
- 轻量交互：Gantt 支持本地探索性调整，但当前不回写后端。

## 5. 页面详细说明

### P-01 登录页

#### 5.1 页面目标

- 解决用户进入系统前的认证问题。
- 提供最小必要入口：登录 + 语言切换。

#### 5.2 入口与出口

| 类型 | 内容 |
| --- | --- |
| 页面入口 | 用户打开系统且未登录 |
| 页面出口 | 登录成功后进入主工作台 |
| 上游页面 | 无 |
| 下游页面 | P-02 主工作台 |

#### 5.3 页面结构

| 区域 | 内容 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 左侧视觉区 | 产品标题、说明文案、背景图 | 是 | 强化 POC 场景感知 |
| 表单区 | 用户名、密码输入框和提交按钮 | 是 | 登录主操作区 |
| 工具区 | 中英文切换按钮 | 是 | 影响全局文案 |
| 反馈区 | 登录错误或服务不可用提示 | 是 | 行内错误反馈 |

#### 5.4 关键交互

| 交互编号 | 用户动作 | 系统反馈 | 成功结果 | 异常反馈 |
| --- | --- | --- | --- | --- |
| UI-01 | 输入用户名密码并提交 | 按钮进入 pending 状态 | 成功登录并进入工作台 | 无效凭证/服务不可用提示 |
| UI-02 | 点击中英文切换 | 页面文案即时刷新 | 当前语言被本地保存 | 登录中时禁止切换 |

#### 5.5 页面状态

| 状态 | 触发条件 | 页面表现 | 用户可执行动作 |
| --- | --- | --- | --- |
| 默认态 | 初次进入未登录 | 展示完整登录页 | 输入账号、切换语言 |
| 提交中 | 提交登录表单 | 登录按钮 pending | 等待返回 |
| 错误态 | 登录失败/服务不可用 | 展示错误提示文案 | 重试登录 |
| 已认证跳转态 | 会话有效或登录成功 | 登录页隐藏 | 进入主工作台 |

#### 5.6 原型与备注

- 原型链接：待补充。
- 截图位置：可使用当前 `index.html` 页面截图。
- 特殊说明：当前没有注册、找回密码、多组织切换等能力。

### P-02 主工作台

#### 5.1 页面目标

- 为已登录用户提供统一入口，完成样例排产、数据刷新、版本浏览和结果查看。
- 显示当前系统总体状态和最新任务状态。

#### 5.2 入口与出口

| 类型 | 内容 |
| --- | --- |
| 页面入口 | 登录成功或已有有效会话 |
| 页面出口 | 登出返回登录页；打开账号设置进入 P-05 |
| 上游页面 | P-01 登录页 |
| 下游页面 | P-03 版本列表与详情区、P-04 Gantt 结果区、P-05 账号设置弹窗 |

#### 5.3 页面结构

| 区域 | 内容 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 顶部 Hero 区 | 当前用户、运行样例、刷新、登出、账号设置、最新任务状态 | 是 | 当前主操作入口 |
| 概览卡片区 | 版本总数、已发布数、当前选中状态、最近刷新时间 | 是 | 快速概览 |
| 主内容区 | 左侧版本面板 + 右侧 Viewer | 是 | 主要工作区域 |
| 反馈区 | 任务状态文案 | 是 | 任务执行反馈 |

#### 5.4 关键交互

| 交互编号 | 用户动作 | 系统反馈 | 成功结果 | 异常反馈 |
| --- | --- | --- | --- | --- |
| UI-01 | 点击 Run Sample Schedule | 任务状态变为提交中/运行中 | 新版本生成并自动加载 | 提示提交失败或求解失败 |
| UI-02 | 点击 Refresh Data | 重新加载版本列表 | 页面数据刷新 | 提示刷新失败 |
| UI-03 | 点击 Account Settings | 打开账号设置弹窗 | 进入 P-05 | 无 |
| UI-04 | 点击 Sign Out | 清理状态并返回登录页 | 会话退出成功 | 即使请求失败也清空本地状态 |

#### 5.5 页面状态

| 状态 | 触发条件 | 页面表现 | 用户可执行动作 |
| --- | --- | --- | --- |
| 默认态 | 已登录且版本正常加载 | 展示完整工作台 | 运行样例、刷新、查看版本 |
| 加载态 | 初始刷新/提交任务/刷新数据 | 部分控件 pending | 等待系统返回 |
| 空态 | 无版本数据 | Viewer 提示无版本可选 | 运行样例排产 |
| 错误态 | 刷新失败/会话异常 | 展示错误或跳回登录页 | 重试或重新登录 |

#### 5.6 原型与备注

- 原型链接：待补充。
- 截图位置：当前工作台首屏。
- 特殊说明：当前没有真实业务录入表单页。

### P-03 版本列表与详情区

#### 5.1 页面目标

- 让用户浏览历史版本、查看版本状态并定位当前关注的方案。
- 在右侧详情区展示选中版本的摘要信息。

#### 5.2 入口与出口

| 类型 | 内容 |
| --- | --- |
| 页面入口 | P-02 主工作台加载完成 |
| 页面出口 | 选择版本后进入 P-04 的结果查看 |
| 上游页面 | P-02 主工作台 |
| 下游页面 | P-04 Gantt 结果区 |

#### 5.3 页面结构

| 区域 | 内容 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 左侧版本面板 | 版本列表、面板折叠、状态摘要 | 是 | 列出所有版本 |
| Viewer 标题区 | 版本名称、状态、创建时间、发布时间 | 是 | 当前版本摘要 |
| KPI 区 | 四个 KPI 卡片 | 是 | 结果概览 |
| 操作区 | Publish Version 按钮 | 是 | 当前版本管理动作 |

#### 5.4 关键交互

| 交互编号 | 用户动作 | 系统反馈 | 成功结果 | 异常反馈 |
| --- | --- | --- | --- | --- |
| UI-01 | 点击某个版本 | 加载对应 gantt-data | Viewer 切换到目标版本 | 提示版本加载失败 |
| UI-02 | 点击 Publish Version | 按钮禁用并发起请求 | 当前版本置为 PUBLISHED | 提示发布失败 |
| UI-03 | 折叠左侧版本面板 | 面板宽度变化 | 提升可视区空间 | 无 |

#### 5.5 页面状态

| 状态 | 触发条件 | 页面表现 | 用户可执行动作 |
| --- | --- | --- | --- |
| 无版本选中 | 初始为空或无数据 | 标题显示 No version selected | 运行样例或选择版本 |
| 已选中草稿版 | 选择 DRAFT 版本 | 展示详情且发布按钮可用 | 发布、查看 Gantt |
| 已选中已发布版 | 选择 PUBLISHED 版本 | 发布按钮禁用 | 查看结果 |
| 列表空态 | 无版本数据 | 左侧列表为空 | 运行样例 |

#### 5.6 原型与备注

- 特殊说明：当前没有版本 diff 视图，也没有单独回滚入口。

### P-04 Gantt 结果区

#### 5.1 页面目标

- 展示资源时间轴、任务分配、停机窗口和 KPI 对应的结果细节。
- 支持本地探索性拖拽，不改变后端结果。

#### 5.2 入口与出口

| 类型 | 内容 |
| --- | --- |
| 页面入口 | 选中某个版本后自动加载 |
| 页面出口 | 重置草稿后回到版本原始结果 |
| 上游页面 | P-03 版本列表与详情区 |
| 下游页面 | 无独立下游页面 |

#### 5.3 页面结构

| 区域 | 内容 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 工具栏 | 缩放、适配、重置草稿、草稿状态 | 是 | 当前主要操作入口 |
| 图例区 | Task/Late/Pinned/Draft/Conflict/Downtime | 是 | 解释颜色和状态 |
| 时间轴区 | 资源行、时间刻度、任务条、停机条 | 是 | 结果主体 |
| 详情区 | 当前任务或当前版本说明 | 否 | 可折叠 |

#### 5.4 关键交互

| 交互编号 | 用户动作 | 系统反馈 | 成功结果 | 异常反馈 |
| --- | --- | --- | --- | --- |
| UI-01 | 点击缩放/适配按钮 | 时间轴重绘 | 视图缩放成功 | 无 |
| UI-02 | 拖拽非 pinned 任务条 | 生成本地 draft 状态 | 任务条位置更新 | 若冲突则高亮 conflict |
| UI-03 | 点击 Reset Draft | 清空本地草稿 | 恢复原始版本结果 | 无 |
| UI-04 | 点击图例/详情切换 | 面板折叠/展开 | 提升视图空间 | 无 |

#### 5.5 页面状态

| 状态 | 触发条件 | 页面表现 | 用户可执行动作 |
| --- | --- | --- | --- |
| 无版本态 | 未选中版本 | 显示空提示 | 选择版本 |
| 无行数据态 | 版本 rows 为空 | 显示 no rows 提示 | 切换版本 |
| Clean 态 | 无本地草稿 | 工具栏显示 No local draft | 缩放、查看 |
| Dirty 态 | 产生本地草稿 | 工具栏显示 draft 状态 | 继续拖拽或重置 |
| Conflict 态 | 草稿与任务/停机重叠 | 任务条高亮冲突 | 调整位置或重置 |

#### 5.6 原型与备注

- 原型链接：待补充。
- 截图位置：当前 Gantt 面板。
- 特殊说明：当前交互只在前端生效，不回写后端，也不会触发重新求解。

### P-05 账号设置弹窗

#### 5.1 页面目标

- 为已登录用户提供最小账号维护能力。
- 在不离开主工作台的情况下修改用户名和密码。

#### 5.2 入口与出口

| 类型 | 内容 |
| --- | --- |
| 页面入口 | 点击主工作台右上角 `Account Settings` |
| 页面出口 | 提交成功后留在弹窗；关闭后回到工作台 |
| 上游页面 | P-02 主工作台 |
| 下游页面 | P-02 主工作台 |

#### 5.3 页面结构

| 区域 | 内容 | 是否必需 | 说明 |
| --- | --- | --- | --- |
| 表单区 | 用户名、当前密码、新密码、确认密码 | 是 | 当前唯一账号维护入口 |
| 操作区 | 保存、取消、关闭 | 是 | 弹窗操作按钮 |
| 反馈区 | 成功/失败提示 | 是 | 行内反馈 |

#### 5.4 关键交互

| 交互编号 | 用户动作 | 系统反馈 | 成功结果 | 异常反馈 |
| --- | --- | --- | --- | --- |
| UI-01 | 修改用户名/密码并提交 | 表单进入 pending 状态 | 用户名更新成功 | 当前密码错误/密码过短/不一致提示 |
| UI-02 | 点击取消/关闭 | 弹窗关闭 | 返回工作台 | 无 |

#### 5.5 页面状态

| 状态 | 触发条件 | 页面表现 | 用户可执行动作 |

| 错误态 | 校验失败/接口失败 | 展示错误提示 | 修正输入后重试 |
