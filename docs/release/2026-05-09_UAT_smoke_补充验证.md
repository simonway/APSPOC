## 3. 自动化补丁

为支持这轮补充验证，已增强：

- [scripts/uat_package_smoke.py](/Users/simon/Documents/MyProgramming/APSPOC/scripts/uat_package_smoke.py:1)

新增能力：

- 支持 `--time-limit-seconds`
- 支持 `--num-search-workers`
- 当覆盖求解预算时，自动把轮询超时拉到 `timeLimitSeconds + 60`

原因：

- 直接把 `timeLimitSeconds` 提高到 `300` 时，如果仍保留默认 `180s` 轮询超时，脚本会先于求解完成而误报超时

  - 求解最优性仍不应过度承诺，应以“当前能稳定给出可行解”作为真实口径
